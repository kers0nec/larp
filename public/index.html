  • When you run /forwardall <channel_id> or /forward, the forwarder will use your User Token REST API to fetch channel messages.

  • No bot invite is required in the source server!

Discord Commands Reference

In Discord, use slash commands or prefix commands in your server:

/photo <generate|list|rename|edit>
AI Photo Studio in Discord. Generate artworks in different styles (Cyberpunk, Anime, Synthwave, etc.), list generated photos with IDs, rename your saved photos, and modify/edit photos with custom AI instructions.
/lua <code>
Execute real-time Lua 5.3 code directly in Discord via Fengari Lua runtime. Displays terminal standard output, errors, return values, and attaches the script.
/python <code> (or /py)
Execute real Python 3 code in an isolated sub-process sandbox. Displays stdout, print outputs, calculation results, and syntax errors.
/forwardall <channel_id> [destination_channel_id]
Copy all .txt files (and accompanying images) from the source channel into the destination channel (or current channel if omitted), and automatically forward all future files in real-time.
/purge [all | number]
Purges all messages in the same channel without deleting, recreating, or cloning the channel (keeps channel ID, permissions, topics, and webhooks intact). Defaults to all messages.
/login [token]
Logs in your Discord user session. Pass your user token (/login token:...) to forward from external servers. Responses are ephemeral and strictly invisible to other players in the server.
/exporthtml [destination] [amount] [upload_files] [file]
Exports channel messages into a styled HTML transcript file and sends it to the target channel ID (or current channel). Optionally downloads and re-uploads all attached files (.txt/images/documents) to the destination.
/clear
Deletes the current channel and clones it back with the same permissions, category, and settings to instantly wipe all messages.
/deleteallchannels
Deletes all channels and categories in the entire server and creates a single fresh text channel.
🔒 /lockall channels [action: lock|unlock] [scope: all|text|voice] [reason] Turbo Lockdown
Instantly locks down all server channels for @everyone at high speed using parallel worker batching. Restores instantly with /unlockall channels or prefix .lockall channels / .unlockall channels.
⚡ /role all <role> [action: add|remove] [target: all|humans|bots] Turbo 0.50
High-speed mass role management engine. Gives or removes a role to everybody in the server mad fast (~0.50s pipeline) using parallel worker batching and live progress tracker. Also works via .role all <@role> [add/remove] or .massrole <@role>.
/clone <source_server_id> [destination_server_id]
Replicates an entire Discord server structure (all categories, channels, permission overwrites, roles hierarchy, custom emojis, server icon & name) into the destination server. Also works with prefix: .clone <source_server_id> [destination_server_id].
/antinuke <enable|disable|status|setup>
Master security switch. Automatically sets up 24/7 protection shields (channel/role recovery, anti-bot, anti-mass ban, anti-spam, anti-delete logs).
/security <toggle|view>
View active security shields or customize individual protections (anti-invite, anti-spam, anti-webhook, etc.).
/whitelist <add|remove|list>
Manage trusted admins who are exempt from anti-nuke triggers and rapid-action limits.
⚡ /whitelist2 <add|remove|list|check> <user> (or .whitelist2 / .wl2) DM & Forward Whitelist
Authorizes users to use channel forward commands, HTML exports, and bot utilities directly in Direct Messages (DMs) and locked server channels. Also available via prefix: .whitelist2 add @user.
🎫 /ticket-setup [channel] [category] [support_role] [title] [description] Interactive Tickets
Deploys an interactive support ticket panel with a custom button. Users click the button to open a modal asking for their topic and issue, which automatically creates a private channel with custom staff permission overwrites and HTML transcript generation. Manage tickets using /ticket close, /ticket transcript, or the in-chat button controls.

Why Are Commands Not Responding?

  • Bot Token Missing/Offline: Ensure TOKEN is set in project Environment Variables. If the header badge shows Offline, the bot cannot connect to Discord.
  • Message Content Intent Disabled: In the Discord Developer Portal, click your bot, go to Bot → Privileged Gateway Intents, and turn ON Message Content Intent. Without this enabled, Discord hides message text from bots!
  • Developer Mode & Channel IDs: Turn on Developer Mode in Discord (User Settings → Advanced → Developer Mode), then right-click a channel to copy its exact numeric ID (e.g. 123456789012345678).
  • Bot Permissions: Ensure the bot has View Channels, Send Messages, Read Message History, Embed Links, and Attach Files in both the source and target channels.
